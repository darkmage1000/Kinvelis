# Wildbond — mobile creature-collector / survival / camp automation (Unity 6)

Unity 6000.0.62f1 LTS · URP 17 (Assets/Settings/Mobile_RPAsset) · new Input System · Android target · MCP for Unity bridge.
All IP is original (kin, names, world "Rimewild Isle"). Inspired by Aniimo (world/exploration) and Palworld (base/worker systems).

## Run
Open `Assets/Scenes/Main.unity` → Play. The scene holds one `Game` object with `GameManager`; everything else is built in code.
If content/materials are missing: menu **Wildbond > Setup Project**. Content assets live in `Assets/Resources/Content` (tweak in inspector; seed source is `ContentSeed*.cs`).
Keyboard: WASD, RMB look, F/click attack, G seed, E use, Space jump, Q roll, C sneak, Shift sprint, R kin, T kin skill, B build, Tab menu, X rotate, Enter place, L / middle mouse lock on, [ ] previous / next target.

## Architecture (Assets/Scripts)
- **Core/** `GameManager` (bootstrap + frame order + game rules: XP, loot, capture registration, death, goals, autosave), `QualityProfile` (Low/Med/High budgets), `RenderAssets`, `GameEvents`.
- **World/** `WorldGen` (pure, thread-safe analytic height/biome/color — 4096 m island, 3 biomes via warped Voronoi), `ChunkManager` (64 m chunks, threaded mesh builds, 3 LOD rings + skirts, GPU-instanced props, node spatial hash, depletion/respawn), `PropCatalog`, `ChunkBuilder`, `EnvironmentSystem` (day/night, regional weather, sky dome, fog, water), `Landmarks` (+ alpha sites), `ResourceNode`/`WorldCollision` (physics-free circle collision).
- **Creatures/** `CreatureData` (serializable individual: level, traits, shimmer/alpha/regional/mutation), `CreatureFactory` (rolls), `ModelBuilder` + `CreatureRig` (part-based procedural models & animation, meshes cached per model key), `CreatureActor` (+ `.Wild/.Companion/.Worker` partial brains), `CreatureSpawner` (pooling, capped population, LOD sim, alpha sites), `CreatureRegistry`.
- **Combat/** `Combat` (formula, element chart, statuses), `ProjectileSystem` (pooled), `Fx` (2 shared particle systems via Emit).
- **Capture/** `CaptureSystem` (thrown Tether Seeds, lead + homing, 3-shake roll: per-shake p^(1/3)). `Chance`: HP curve (`HpCurve`, linear between points) full 20% · 50% 45% · 25% 65% · 10% 90% · ≤5% 99%; rarity/shimmer don't matter (one exception: legendaries x0.453, see Legend hunts); seed tiers = level rating (`SeedLevelCap`: Tether 20 / Ironbark 40 / Starbloom any, −6%/level over, min ×0.15) + small `SeedBonus` (×1 / 1.15 / 1.35); overkill: kin below `SeedTierFloor` (0/20/40) lerp toward the cap over 20 levels; alpha ×0.5. Cap 99%, 100% only with all 7 Tetherbloom relics.
- **Base/** `BaseManager` (camp, storage, workers, craft orders, near=actors / far+offline=abstract sim), `Building`, `BuildPlacement`.
- **Player/** `PlayerController`, `PlayerStats` (level/skills/bag), `KinRoster` (party 5 / camp / box, companion), `CameraRig`.
- **Input/** `InputHub` (single source for gameplay input), `TouchControls` (joystick, look pad w/ pinch, buttons).
- **UI/** code-built uGUI: `HUD`, `MenuUI` (+Tabs), `UIFactory`, `MapTexture`. **Audio/** `SynthAudio` (all SFX + biome music synthesized). **Save/** JSON in persistentDataPath.
- Shaders: `Wildbond/VertexLit` (vertex colors, sRGB→linear, instancing, shadows), `Water`, `Sky`, `Particle`.

## Rules of thumb
- Gameplay reads `InputHub` only. New content = add to `ContentSeed` (or create assets) — no code changes needed for species/items/recipes/buildings.
- Never add per-tree GameObjects; props are instanced per chunk. Heights come from `WorldGen.Height`, never raycasts.
- Stop Play mode before editing scripts via MCP (domain reload during play breaks statics).
- Unity 6 writes 2-line `.meta` files for scripts — that's normal.

- **Combat pacing (2026-10-06):** `CombatSystem.Compute` now = power × `LevelScale(attacker)` × clamp((atk/def)^`StatExponent` 0.6, 0.35..4) × element/crit. Kin: `KinPowerScale` 0.32 × (1 + 0.12 per level) — same growth as kin HP, so an even-level fight is the same length at any level (weakest move ≈ 6% of an average kin's HP, a same-element 16-power move ≈ 10%). Player swings: `PlayerPowerScale` 0.2 × (1 + 0.04 per level), ≈ 4% per swing with a matching weapon. Level gaps compound (Lv +3 ≈ 2.5× swing in the exchange, Lv +10 ≈ 30% per hit, Lv 60 one-shots Lv 1 commons). Before this, damage ignored level entirely (2-3 hit fights at low level, slow at high level). Tune the three consts, not ability powers. Weapon numbers are shown as "Attack power".
